# 《别迟到》

《别迟到》是一款移动端优先的时间管理文字游戏。玩家需要在年末连续完成 10 个工作日的打卡，在睡眠、金钱、通勤时间和随机事件之间做取舍。

## 当前核心规则摘要

- 游戏包含 Day 1~12：10 个工作日和中间 2 个周末。
- 固定 00:00 睡前准备，09:00 前完成打卡。
- 目标睡眠为 8 小时；睡眠不足会产生睡眠债，并影响紧接着的早晨 snooze。
- 通勤方式为地铁、快车和专车。
- 地铁固定 60 分钟、便宜并免疫天气与事件；快车可能取消；专车不会取消但仍受天气和事件影响。
- 首轮平衡实验将 snooze 上限设为 6 次（每次仍为 9 分钟），睡眠债衰减仍为 0.5。
- 初始余额 50 元，Day 1~12 每天发 20 元；余额不允许为负。
- 迟到后最多可以贿赂一次，费用 180 元；拒绝、付不起或再次迟到都会失败。
- 通关是主目标；最终余额是通关后的次级分数。失败局可以展示余额，但不与通关成绩比较。

完整机制和数值请以 `game_spec.md` 为准，不要以本页摘要代替规格。

## 状态模型

引擎采用带 `phase` 的判别状态，由 reducer 根据当前阶段限制合法操作。主要阶段为：

```text
intro → bedtime → sleeping → wakeup → commute → office/bribe → next day/result
```

工资、到货、天气和事件将在进入当天时一次性处理；当晚新增睡眠债会立即影响紧接着的早晨。UI 不能绕过引擎直接制造非法流程。
