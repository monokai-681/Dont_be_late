# 《别迟到》

《别迟到》是一款移动端优先的时间管理文字游戏。玩家需要在年末连续完成 10 个工作日的打卡，在睡眠、金钱、通勤时间和随机事件之间做取舍。

## 项目状态

当前项目处于 **Phase 3 Web 功能原型**：

- Phase 0：机制、数值和状态流设计完成。
- Phase 1：TypeScript 基础设施、核心函数、商店、reducer、模拟器和测试完成。
- Phase 2：CLI 可交互版完成。
- Phase 3：React/Vite Web 原型已可运行，包含完整玩家流程、渐进教学、规则手册、购物车、移动端状态栏和结算调试报告。
- 当前重点：真实浏览器完整试玩、移动端体验修正、stock 背景图接入和发布验收。

核心引擎已经可以从 Day 1 运行到 Day 12，并通过 TypeScript 编译和整局回归测试。当前默认启用高睡债地铁坐过站风险；地铁信号故障逻辑保留为可注入配置，但默认关闭。

## 快速开始

环境要求：Node.js `>=20.19`。

```bash
npm install
npm run build       # 检查引擎和 Web 生产构建
npm test            # 运行全部测试
npm run dev         # 启动 Web 开发服务器
```

其他入口：

```bash
npm run cli                 # 终端手动玩一局
npm run cli -- my-seed      # 用指定 seed 重玩
npm run sim -- 1000         # 运行 1000 局模拟
npm run sim:10k             # 运行 10000 局模拟
```

## 核心玩法摘要

- 游戏循环为 Day 1～12：10 个工作日，中间包含 Day 6～7 两个周末。
- 每个工作日从 00:00 的睡前准备开始，目标是在 09:00 前完成打卡。
- 睡眠不足会形成睡眠债，并影响紧接着的早晨 snooze 次数。
- 工作日可购买枕头、眼罩、耳塞、DORA 和智能台灯；永久物品次日到货，DORA 当晚生效。
- 通勤方式为地铁、快车和专车。地铁免疫天气与城市事件，但睡眠债达到 180～300 分钟时会产生 0%～100% 的坐过站概率，并额外耗时 20 分钟。
- 快车可能取消；专车不会取消，但快车和专车会受到下雪和城市事件影响。
- 第一次迟到可以选择支付 180 元贿赂；拒绝、付不起或再次迟到都会导致失败。
- 通关是第一目标，最终余额是通关后的次级分数。

完整规则、数值和边界行为以 [`game_spec.md`](game_spec.md) 为准。

## 引擎与 Web 架构

```text
src/engine/       纯 TypeScript 规则引擎、reducer、RNG、商店和数值配置
src/simulator.ts  多策略批量模拟器
src/cli.ts        终端交互入口
src/web/          React Web UI、展示模型、教学和本地学习记录
src/content/      Web 与 CLI 共用的简体中文运行时文案
src/tests/        引擎、CLI、模拟器、telemetry 和 Web 展示模型测试
```

UI 只能通过 `src/engine/index.ts` 使用公开 API，不能绕过 reducer 直接修改游戏状态。随机性通过可复现 seed 注入，便于测试、模拟和复盘。

引擎内部使用以下状态阶段：

```text
intro → bedtime → sleeping → wakeup → commute → office/bribe → result
```

`sleeping` 和 `wakeup` 目前是引擎阶段，Web 会自动结算后进入通勤页面，未来可以加入睡眠过渡表现。

## Web 原型说明

- 当前以灰色背景验证信息结构，页面内 CSS 美术占位已经移除。
- 后续使用来源和许可可追溯的 stock 图片，经高斯模糊和暗化后作为背景；不使用生成式图片。
- 规则手册和教学提示记录保存在设备本地，不上传玩家数据。
- 结算页可复制包含 seed、版本、数值配置、每日记录和本局决策事件的 JSON，方便试玩反馈。
- 生产部署目标是 GitHub Pages；项目站点需要配置 Vite 的 base path。
